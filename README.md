# ADS Projects

This repository contains my university DSA (Algorithms and Data Structures) projects.

Implemented projects:
- `ilgasilgas` – C implementation of a custom radix 256 big-integer type with basic arithmetic operations.
- `priemimoKomisija` – Commission/queue system using deque and queue data structures.
- `vladoves` – Triangular N-queens problem solver using backtracking with configurable search modes.
